# Slope Stability Analyzer V2

V2 adds:
- Two soil layers
- Material-dependent slice properties
- Surcharge
- Horizontal/vertical seismic input fields
- Simplified Bishop and Ordinary/Fellenius
- Circular surface search
- Critical surface + search visualization
- Slice table
- Parametric sensitivity sweeps

This is a prototype. The implementation must be independently benchmarked against hand calculations and validated reference cases before engineering design use.
